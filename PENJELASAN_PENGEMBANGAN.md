# Pengembangan Sistem (*Development*)

Setelah menentukan kebutuhan dan menyusun desain sistem pada website CLING, tahapan selanjutnya yaitu pengembangan sistem. Peneliti menggunakan *framework* Next.js versi 16 sebagai fondasi utama aplikasi web yang mencakup sisi *frontend* dan *backend* (API Routes), dengan bahasa pemrograman TypeScript versi 5 dan *library* React versi 18 untuk membangun antarmuka pengguna, serta Tailwind CSS versi 3.4 untuk mendesain tampilan. Pada sisi basis data, peneliti menggunakan Supabase yang berbasis PostgreSQL sebagai sistem manajemen basis data relasional, sekaligus menyediakan layanan autentikasi (Supabase Auth) dan penyimpanan file (Supabase Storage) untuk foto profil dan materi pembelajaran. Untuk fitur *compiler* dan analisis *clean code*, peneliti membangun layanan API terpisah menggunakan *framework* FastAPI versi 0.115 dengan bahasa Python versi 3.11, di mana kode siswa dieksekusi melalui Python Interpreter dan dianalisis menggunakan *library* Pylint versi 3.3 berdasarkan standar PEP 8. Aplikasi Next.js di-*deploy* pada *platform* Vercel, sedangkan layanan Python API di-*deploy* pada *platform* Railway menggunakan Docker *container*. Adapun alat pengembangan yang digunakan meliputi Visual Studio Code sebagai *code editor*, Git dan GitHub sebagai *version control system*, serta Vercel CLI untuk proses *deployment*.
